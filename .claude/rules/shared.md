# Shared building blocks: current state

What exists in the code, one bullet per AP. Update it when an AP changes this area (projektplan §2.4).

- UI building blocks (AP 0.4) live in `shared/ui`, shown at `#/lab/components`: `appButton`/`appIconButton` (attribute directives on native `<button>`/`<a>`), `appIcon` (Bootstrap icon on `<i>`), `app-panel`, `app-badge`, `app-tabs` (Angular Aria), `appMenu`/`appMenuItem` (look of Angular Aria menus), `appNavLink` with `NavItem` (navigation lists), `app-empty-state`, `app-skeleton`, `app-stat-tile`, `app-price-change`, `ToastService`, `app-dialog` and `openConfirmDialog`. Reuse them. Tabs and menus use `@angular/aria` (E-16); everything else from the CDK.
- Infrastructure (AP 0.3): money types, rounding and price grid in `shared/domain`; formatting functions in `shared/util` (with `MISSING_VALUE` `–` and `formatOptional`) and the pipes over them in `shared/ui/pipes` and `clock/ui/pipes` (game date and time). Templates format only through these pipes. Reuse them instead of rounding or formatting ad hoc.
- Amount input `app-amount-input` (`FormValueControl<Cents | null>`) over `parseAmountInput`/`formatAmountInput` (`shared/util`); wall-clock date and time with `formatDateTime` and its pipe (AP 2.4).
- Price highlight (AP 4.4, US-MK-05): directive `appValueFlash` (`shared/ui/value-flash`, `[appValueFlash]="value"`, `[enabled]`) tints a changed number `up`/`down` for `VALUE_FLASH_MS` 600 ms, only `motion-safe:`; the first and unchanged values don't flash; example on `#/lab/components`, component test `value-flash.directive.spec.ts`. The device setting switches it off since AP 6.2 (`VALUE_FLASH_ENABLED`, below).
- Formatting for the instrument page (AP 4.5): `formatSignedPrice(change, fractionDigits)` (a price change with the decimals of its price), `formatCompactEuros` (`1,2 Mrd. €`, PS §10.4) in `shared/util/format.ts` with the pipes `formatSignedPrice`, `formatCompactEuros` and `formatFixedPrice` (an amount with given decimals, e.g. the spread with those of the quote) in `shared/ui/pipes`.
- Trading support (AP 5.4): `formatQuantity` (shares in millionths with the decimals they need) with the pipe `formatQuantity`; the pipe `formatSignedCents` over `formatSignedCents` (typographic minus), e.g. the gain or loss in the order ticket. `app-dialog` limits its frame to the height of the CDK pane (`calc(100dvh - 2rem)`, `dialog.component.scss`, the same `maxHeight` every dialog opens with): header and actions stay in view, the content between them scrolls. Dialogs need no own height workaround.
- Follow-up M5: `formatPercent` writes negative ratios with the typographic minus like the formats for changes (`−12,3 %`, PS §10.4); `formatCents`, `formatPrice` and `formatNumber` still use the hyphen-minus for negative values. `parseGermanNumber` (`src/testing/parse.ts`) reads both.
- File download port (AP 6.1): `FILE_DOWNLOAD` (`shared/data-access/file-download/file-download.ts`, root default with a `Blob` URL and a temporary link) saves a text as a download; page tests replace it with `RecordingFileDownload` (`shared/data-access/testing/recording-file-download.ts`, `provideRecordingFileDownload`). The CDK `Clipboard` copies only during a user action, so copy in the click handler itself.
- Settings hooks (AP 6.2): `VALUE_FLASH_ENABLED` (`shared/ui/value-flash/value-flash.config.ts`, `Signal<boolean>`, root default on) switches `appValueFlash` app-wide, `provideAppCore()` feeds the device setting; `ColorSchemeService.applyChangeColors` toggles `colors-blue-orange` on `<html>` (`CHANGE_COLORS`, `BLUE_ORANGE_CLASS` in `color-scheme-service.utils.ts`). `src/styles.css` defines both gain/loss pairs per theme (`--pgo-up-green-red` … `--pgo-down-blue-orange`); `--pgo-up`/`--pgo-down` point at the pair chosen by `.colors-blue-orange`/`.colors-green-red` above the theme class (`#/lab/tokens` measures all four combinations).
- PWA support (AP 6.3): `formatBytes` (decimal units, at most one decimal place, non-breaking space, PS §10.4) with the pipe `formatBytes`; `ColorSchemeService` also sets the `theme-color` meta from the computed `--pgo-bg`.
