Startkapital

Das Startkapital ist der Betrag, den du zu Beginn bereits zum Investieren zur Verfügung hast. Dazu zählen zum Beispiel Ersparnisse, die du direkt in dein Portfolio einbringen möchtest.

Beispiel:
Bei 10.000 € Startkapital beginnt deine Berechnung mit einem Portfoliowert von 10.000 €.

Du kannst auch mit 0 € starten und dein Vermögen nur durch regelmäßiges Sparen aufbauen.
Monatlicher Sparbetrag

Der monatliche Sparbetrag ist die Summe, die dir jeden Monat zusätzlich zum investieren zur Verfügung steht. Eine regelmäßige Einzahlung lässt dein Portfolio Schritt für Schritt wachsen.

Der Betrag wird monatlich deinem Barvermögen gutgeschrieben und kann dann investiert werden.

Beispiel
Mit 250 € pro Monat stehen dir 3.000 € pro Jahr, zusätzlich zu deinem Startkapital, zum Investieren zur Verfügung.

Wähle einen Betrag, den du langfristig und zuverlässig zurücklegen kannst.
